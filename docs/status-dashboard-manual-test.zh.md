# 状态面板手动测试清单

覆盖本轮两项改动：图表统一替换为 ApexCharts、状态面板默认全屏的布局切换。
测试前先启动本地服务，然后打开带 token 的预览地址（token 以实际启动输出为准）：

```
http://127.0.0.1:3080/?token=<启动时输出的 token>
```

基金数据来自工作区里的 `scripts/fund_panel.json`（由 `node scripts/export_fund_panel.mjs` 生成），
文件不存在或格式不对时，基金卡片显示空态。

---

## 1. 默认进入：状态面板全屏

| 项 | 内容 |
| --- | --- |
| 操作 | 直接打开预览地址，不做任何点击 |
| 预期 | 左侧是侧边栏（收起时只留窄条/图标栏，可用 Ctrl+Alt+B 或栏内按钮展开）；右侧「状态面板」铺满侧边栏以外的全部宽度 |
| 预期 | 页面上看不到聊天输入框，聊天列宽度为 0（但仍挂载在后台） |
| 预期 | 面板从上到下依次可见：会话/工作区/基金/任务统计卡片、基金持仓与收益、工作区文件环形图、每日定时任务、后台任务等 |
| 预期 | 浏览器控制台无报错 |

## 2. 从侧边栏打开聊天

| 项 | 内容 |
| --- | --- |
| 操作 | 展开侧边栏，在工作区树里点一条已有会话，或在「工作区」里点「新会话」 |
| 预期 | 不再全屏：左侧出现聊天区，右侧状态面板保持可见（默认约占 45% 宽） |
| 预期 | 状态面板自动展开到「状态面板」标签；即使点的是复用的空白会话，也会自动展开 |
| 预期 | 切换瞬间不整页刷新；聊天草稿、面板滚动位置不丢 |
| 预期 | 若打开前已选过基金（如「芯片 017746」），打开聊天后仍是同一只基金 |

## 3. 关闭聊天，回到全屏面板

| 项 | 内容 |
| --- | --- |
| 操作 | 在聊天区标题栏最右侧点关闭按钮（悬停提示「关闭聊天，展开面板」） |
| 预期 | 聊天区消失，状态面板重新铺满侧边栏以外的整页 |
| 预期 | 面板滚动位置、已选基金 chip、图表状态都保留，不发生重新加载 |
| 预期 | 侧边栏仍然在，可继续从里面发起/打开聊天 |

补充：侧边栏里点「插件」等全局面板时，会自动退出全屏面板模式，变成「中间面板 + 右侧状态面板」。

## 4. 三个环形图（原手写 SVG，现为 ApexCharts donut）

| 图表 | 操作 | 预期 |
| --- | --- | --- |
| 工作区文件 | 滚动到「工作区文件」卡片 | 环形图按文件类型分色，中心显示总数，右侧图例显示各类数量与占比 |
| 会话状态 | 滚动到「会话状态」 | 环形图区分运行中/空闲会话，中心显示总数 |
| 任务状态 | 同一卡片内 | 有任务时按状态分色；无任务时显示灰色整环 + 中心「暂无数据」 |

三张图都应在浅色/深色主题下颜色正常，切换主题后环形图颜色跟随变化。

## 5. 基金持仓与收益折线图

| 项 | 内容 |
| --- | --- |
| 操作 | 确认基金 chip 只列出当前在持的基金（如「电网 023638」「芯片 017746」），已清仓的不出现 |
| 操作 | 点另一个 chip | 标题、区间收益、曲线、买卖点同时切换 |
| 操作 | 悬停曲线上任意位置 | 出现 tooltip，显示日期与百分比收益（如 `08-13 电网: -14.66%`） |
| 查看 | 图表元素 | 成本线为虚线；0% 处有基准线；买入为绿色小圆点、卖出为红色小圆点；关键买卖点旁标注日期 + 买/卖，标注不重叠 |
| 操作 | 点面板右上角刷新按钮 | 数据重新拉取，卡片与图表数值刷新，控制台无报错 |
| 操作 | 缩放窗口宽度 | 图表随容器重绘，不溢出、不裁切 |

## 6. 已知限制

- 状态面板依赖一个已挂载的会话；如果本地完全没有会话，面板可能没有可挂载的位置，需先在侧边栏新建/打开一个会话。
- 手动把右侧面板收起后，聊天会占满主区域；再次打开聊天不会强行重开你手动关掉的面板（首次进入聊天会自动展开）。
- 右侧栏自带的「分栏」（Ctrl+\）可以把面板拆成两栏，这是既有能力，不属于本轮改动；若出现两个状态面板实例，是分栏状态导致的。
- 面板标题栏里既有的「全屏」按钮仍走旧的全屏路径（会覆盖左侧栏）；本轮的「保留侧边栏 + 面板占满」是默认进入和关闭聊天时的路径，两者刻意分开。
- 窄屏（< 768px）时侧边栏变为抽屉，面板接近全屏显示，气泡 tooltip 可能贴近屏幕边缘。
- 图表的文字单位与刻度由 ApexCharts 自动计算，和旧手写 SVG 相比刻度位置、字号会有细微差别（属正常渲染差异）。
- 浏览器版本过旧（不支持 ResizeObserver / MutationObserver）时，面板宽度与主题色可能不跟随。
